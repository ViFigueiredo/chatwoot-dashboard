# Instruções para IA e Agentes

Este projeto possui uma documentação abrangente e diretrizes detalhadas sobre a arquitetura, estrutura, scripts e fluxos de dados no arquivo **[AGENTS.md](./AGENTS.md)**.

Antes de prosseguir com qualquer análise, refatoração, implementação de novas funcionalidades ou correções de bugs, **leia e siga rigorosamente as diretrizes e especificações técnicas descritas no [AGENTS.md](./AGENTS.md)**. Ele serve como a fonte da verdade para o comportamento de integração da API do Chatwoot, regras de negócio de prospecção, e padrões de desenvolvimento adotados neste repositório.
